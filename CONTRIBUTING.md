# Contributing

Thanks for helping improve Awesome Prop Firms. Suggestions from founders, operators, traders and vendors are all welcome, including vendors suggesting their own product, as long as the entry follows the rules below.

## How to suggest an entry

1. Open a pull request that adds one entry per line to the right section of `README.md`.
2. Or, if you'd rather not edit the file, open an issue with the name, the link and the section.

One pull request can add several entries, but keep each one on its own line.

## Entry format

```markdown
- [Name](https://example.com/) - One neutral sentence on what it is.
```

- Use the name the product uses for itself.
- Put a space, a hyphen and a space between the link and the description.
- Write one sentence that starts with a capital letter and ends with a full stop.
- Add the entry in alphabetical order within its section, ignoring case.
- Link to the homepage. Link to a deeper page only for an article, a regulator notice, a document or a product that has no homepage of its own.

## What gets accepted

- **Real and live.** The link must load, and the product must be available today. A link checker runs on every pull request and every week, and entries whose links die are removed.
- **Relevant.** It should help someone start or run a prop firm, or help a prop trader. Generic tools with no connection to prop trading are left out.
- **Neutral.** Describe what the product is, in plain words, from its own website. Don't write "best", "leading", "#1", "trusted by" or anything else that ranks it or can't be checked.
- **No prices.** Prices change and go stale. Leave them out, along with discount codes and promotions.
- **No affiliate, referral or tracking links.** Don't add `ref`, `aff`, `utm_` or similar parameters. Pull requests with affiliate links are closed.
- **Reputable sources for reading.** Articles in the legal and industry section should come from regulators, courts, law firms or established news outlets.
- **No individual prop firms.** This list covers the tools, services and reading around prop firms, not the firms themselves. Comparison and review sites are listed in the traders' section instead.

## Disclosure

If you work for, own or are paid by the product you're adding, say so in the pull request. It doesn't stop the entry from being accepted, but the description will be held to the same neutral standard as everything else.

This list is maintained by [PropSim](https://propsim.markets/?utm_source=github&utm_medium=readme&utm_campaign=awesome-prop-firms), which sells prop firm software. PropSim and its competitors are listed side by side, alphabetically and under the same rules. The links to PropSim's own site carry UTM tags so PropSim can see visits that come from this list; no other link does.

## Reporting a problem

Open an issue if a link is dead, a description is wrong or out of date, or an entry no longer belongs on the list.
